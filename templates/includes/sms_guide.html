SMS COMMANDS GUIDE

Send SMS to 0700-000-000 to use Watukazi from any phone. No internet required!

WORKER COMMANDS
  • REGISTER worker username password location - Create account
  • ADD_SKILL Plumbing - Add a skill
  • MY_SKILLS - View your skills
  • JOBS - Find jobs near you
  • APPLY 5 - Apply for job
  • MY_JOBS - View applications
  • AVAILABLE - Set available status
  • STATUS - View your profile
  • HELP - Show all commands
EMPLOYER COMMANDS
  • REGISTER employer username password location - Create account
  • POST|Title|Desc|Location|Budget|Skills - Post a job
  • MYJOBS - View your jobs
  • JOB 5 - View job details
  • APPLICANTS 5 - View applicants
  • ACCEPT 10 - Accept worker
  • REJECT 10 - Reject worker
  • COMPLETE 10 4 - Complete job with rating
  • HELP - Show all commands

📱 Example SMS:

"REGISTER worker john123 pass123 Nairobi"

After registration, you'll receive confirmation via SMS
